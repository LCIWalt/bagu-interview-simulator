# Bagu Interview Simulator 使用说明

## 首页与练习入口

- 「开始练习」：进入自由练习，逐题作答并查看评分卡。
- 「开始实战」：配置岗位/级别/时长后进入模拟面试。
- 「最近练习」：列出最近的练习与实战会话。

## 最近练习：多选删除

1. 在首页「最近练习」列表**长按**任意一条记录，进入多选模式。
2. 进入后，点击其他记录可加入/移出选择；顶部显示「已选 N 项」。
3. 点击右上角**垃圾桶**按钮。
4. 在确认弹窗中点击「删除」。

删除范围（不可恢复）：

- 会话本身
- 该会话的全部回答与评分
- 会话记忆、报告与关联的申诉数据

> 删除不可撤销。需要保留的记录请先在报告页导出 Markdown。
> 用户题库、笔记、收藏与 API Key 不会被删除。

退出多选：点击左上角关闭按钮，或删除完成后自动退出。

## 复盘

- 首页「复盘」或底部/侧边导航进入。
- 展示最近会话、分数趋势与主题掌握度。
- 练习与实战完成后点击记录进入六段式整场报告：
  1. 一句话结论
  2. 能力分布
  3. 薄弱主题
  4. 7 天计划
  5. 面试官视角
  6. 逐题复盘
- 没有作答记录的空会话不会弹报告/面板，会在底部提示并可直接去练习。

## 题库

- 按岗位（移动端/后端/前端/算法）、主题、难度筛选。
- 长按/点击题目进入详情；支持收藏、笔记、隐藏。
- 内置 728 道种子题，含 480 道 Flutter、83 道 Dart、97 道 Android。

## 设置

- 模型供应商：面试官、评分官、TTS、联网核查分别配置。
- 联网核查可选 Tavily 或 OpenAI 兼容 Web Search。
- 「语义检索（实验）」：本地 bge 模型，需先重建索引。
- 「用量」：只统计 `llm_calls` 中的 token，不估算费用、不设上限。

## 数据与隐私

- 数据默认只在本机；API Key 存在系统钥匙串。
- macOS 自用构建无 App Sandbox（ADR-0006），仅建议本地 DMG 分发。
