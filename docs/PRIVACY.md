# 隐私与数据说明（v0.5）

MockMate 是本地优先的自用工具，没有账号体系与自有后端。

## 数据存在哪里

| 数据 | 位置 | 说明 |
|---|---|---|
| API Key | macOS legacy Keychain（无 sandbox）/ iOS Keychain / Android Keystore（`flutter_secure_storage`） | 不写数据库、不进日志 |
| 题库、回答、评分、笔记、记忆 | 应用支持目录 `mockmate.sqlite` | 默认只在本机 |
| 日志 | 应用支持目录 `logs/`，按天滚动保留 7 天 | 统一 `redact()`（key/token/邮箱/手机号/内网域名） |
| 报告 / 记忆导出 | `reports/`、`sessions/<id>/memory.json` | 用户主动导出 |
| 向量缓存 | `question_embeddings`（若启用） | 本地模型生成 |

## 会发出的网络请求

1. 配置的 LLM provider（默认 DeepSeek）：面试官、评分官、记忆/断言抽取的对话内容。
2. 配置的 TTS provider（默认 OpenAI 兼容）：面试官文本转语音；不发送用户回答。
3. 配置的搜索 provider（Tavily）：仅当用户配置 key 且触发核查时，发送断言检索式与目标 URL。
4. 题库更新：GitHub Release API 与资产下载（不携带用户回答）。
4. 无自建服务、无遥测、无崩溃上报（默认关闭）。

## 不采集

- v1 **不申请麦克风权限**，不录音；语音输入由系统输入法完成，音频可能由输入法厂商处理。
- 不做人格/情感记忆，不做广告画像。

## 删除

- 单场报告可在报告页删除（级联回答/记忆/汇总）。
- 卸载 App 或删除应用支持目录即可清除全部本地数据；API Key 需在系统钥匙串中删除。
- 日志可在设置页导出后自行删除。

## 风险提示

- 回答文本可能包含公司内部信息，默认只存本地；导出/分享前请自行脱敏。
- 联网核查只把断言与 URL 发给搜索服务，不上传完整回答；但检索式可能包含敏感片段。
